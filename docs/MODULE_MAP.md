  - `ws`: Room (`GameRoomDO`) or matchmaking (`MatchmakerDO`) connection.
  - `presenceWs`: Persistent `/ws/presence` connection to `MatchmakerDO` for live online status (`onlineUsers`) and real-time social notifications (`notifyUserRealtime`).
  - `ensureConnected()`: Safe re-attach used when the internet comes back after an outage; re-opens the last URL (room / matchmaking / presence) without resetting the session target.
- [`client/src/services/netMonitor.ts`](client/src/services/netMonitor.ts): App-wide internet connectivity monitor. Web uses browser `online`/`offline` events plus a lightweight heartbeat probe against the CDN worker; native uses periodic HEAD probes only (no NetInfo native dependency). Updates `store/netStatus.ts`.
- [`client/src/store/netStatus.ts`](client/src/store/netStatus.ts): Zustand store (`useNetStatus`) for connectivity state: `online`, `offlineSince`, game grace deadline (`graceEndsAt`, `OFFLINE_GAME_GRACE_MS = 20s`), and reconnect-flash timestamp.
- [`client/src/components/ConnectionStatusOverlay.tsx`](client/src/components/ConnectionStatusOverlay.tsx): Global non-blocking connectivity pill rendered at RootNavigator root (`pointerEvents="none"`). Shows an animated Wi-Fi-off banner with a countdown progress bar while offline in a game, and a mint "connected again" flash on recovery.
- Offline-in-game flow (RootNavigator): when the internet drops on a game screen (`quiz_arena`, `lobby`, `intermission`, `duel_versus`, `matchmaking`), the player is kept in the game for the grace period; if still offline at expiry, they are dropped from the game and routed to `ReconnectScreen`, which auto-returns home as soon as connectivity is restored. `.vercelignore` keeps heavy CDN-served media (`client/assets/{images,sounds,music}` and stale `client/dist` asset copies) out of Vercel uploads; sources stay in GitHub and only app logos are deployed.
